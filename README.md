# Focal Engine Test Platform

How to clone:<br />
git init<br />
git remote add origin https://github.com/Azzinoth/FocalEngineTestPlatform<br />
git fetch origin<br />
git checkout -b dev origin/dev<br />
git checkout -b master origin/master<br />
git checkout dev<br />
git submodule update --init --recursive<br />
